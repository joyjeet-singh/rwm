# Retired keys

A `{{key}}` that leaves the paper, the supplement and the ledger on purpose is listed here (PLAN §1.2 rule 9).
The `keys` gate (G6) compares the current key set against `base_keys.txt`.

Allowed reasons (vocabulary):
- superseded by key X
- a display variant of key X
- a restatement removed in favour of key X
