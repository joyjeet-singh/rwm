Written by S0 on 2026-09-28 against `pre-presubmission` (da74907). Paths are relative to the
repository root (`rwm_repro/`, inside the `PDM/` working folder). Every file:line below was read
at that commit, and line numbers drift once later sessions edit a file, so grep the quoted anchor
rather than trusting a line number. `$PY` means the absolute path of
`PDM/.venv-rwm311/bin/python` (the project `CLAUDE.md` gives it in full), run from the repository
root. No absolute path is written here, because both bundle builders walk `docs/`.

- `PAPER.md` — generated from the template by `scripts/build_paper.py`. Never edit.
- `PAPER.tex` — generated inside `build_paper.py`, which calls `scripts/md_to_tex.py` (`build_paper.py:390`, `:407`). Never edit.
- `PAPER.pdf` — compiled from `PAPER.tex` by `scripts/compile_paper.py` (pdflatex, `compile_paper.py:23`). Its bytes change on every compile (date and `/ID`); compare with those blanked (see `BASELINE_S0.md`).

## 2. Numbers: `paper_numbers.py` and how a key is added

- `scripts/paper_numbers.py` → `results/paper_numbers.json` — collects every number the paper prints. Command: `$PY scripts/paper_numbers.py`.
- Adding a key: inside `main()`, call `put("<key>", <value string>, "<results/artifact path>")`. `put` is at `paper_numbers.py:32-33` and stores `{value, source}`. Pattern to copy: `paper_numbers.py:41,48` reads `J("step0_regimes.json")[...]` and then calls `put("rows", f"{...:,}", "results/step0_regimes.json")`. Then write `{{<key>}}` in the template.
- Small counts as words: `WORDS` dict, `paper_numbers.py:26` (1–13 → "One"…"Thirteen"), used as `WORDS.get(n, str(n))` and `.lower()` mid-sentence.
- Refusal: `build_paper.py:146` asserts that no placeholder lacks a value, and `:149` that no `{{…}}` survives.
- Tables substituted whole: `{{evidence_table}}` (§3.2, template line 408) and `{{appG_table}}` (Appendix E, template line 1904).

## 3. Fast paper build and the prose checks

**Fast build** (the order must hold; `build_paper.py` does not rebuild the PDF):

```
$PY scripts/paper_numbers.py && $PY scripts/build_paper.py && $PY scripts/build_model_card.py && $PY scripts/build_readme.py && $PY scripts/compile_paper.py
```

**Prose checks and gates**, run after the fast build (all passed at S0; see `BASELINE_S0.md`):

```
$PY scripts/ledger_check.py && $PY scripts/check_comparative_claims.py --self-test && $PY scripts/typed_numeral_audit.py && $PY scripts/restatement_index.py && $PY scripts/horizon_sweep.py && $PY scripts/xref_sweep.py && $PY scripts/check_scope_audit.py && $PY scripts/pdf_render_check.py
```

**Build-order lag.** The paper prints counts that the gates write: `{{tn_typed}}` comes from `typed_numeral_audit.py`, and the `{{cc_*}}` counts from `check_comparative_claims.py`. An edit that adds numerals or claims therefore prints stale counts on the first build. After any content edit, run: fast build → gates → fast build again, and require `PAPER.md`, `PAPER.tex`, `MODEL_CARD.md`, `README.md` and `docs/BUILD_CHECKS.md` to be byte-identical to the build before.
